# Ingenium study buddy

A mobile-first chat interface with a custom AI-style avatar and four study shortcuts. Run locally with `npm install` and `npm run dev`; open http://localhost:5173.

The interface is a preview. Messaging, translation, voice, file and image assistance require an AI backend integration. Selected files remain in the browser and are not uploaded.

Run `npm run build` to build and `npm run test:e2e` to check the mobile interface (install the browser first with `npx playwright install chromium`).
